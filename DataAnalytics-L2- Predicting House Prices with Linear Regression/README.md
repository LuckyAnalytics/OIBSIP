# House Price Prediction using Linear Regression

## Objective
This project predicts house prices using the Linear Regression algorithm. It covers the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and model saving.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
Ames Housing Dataset

## Project Workflow
1. Load Dataset
2. Exploratory Data Analysis (EDA)
3. Missing Value Handling
4. One-Hot Encoding
5. Correlation Heatmap
6. Train-Test Split (80/20)
7. Linear Regression Model
8. Model Evaluation (MSE, RMSE, R²)
9. Actual vs Predicted Plot
10. Residual Plot
11. Coefficient Analysis
12. Ridge Regression Comparison
13. Save Model

## Evaluation Metrics
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

The trained model is saved as:
