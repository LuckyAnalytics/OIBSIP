
# Data Cleaning using Pandas

## Objective
Perform data cleaning and basic exploration on the sentiment dataset.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook

## Files
- sentiment_analysis.ipynb
- sentiment_dataset.csv
- requirements.txt

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Open sentiment_analysis.ipynb in Jupyter Notebook.

## Output
- Dataset loaded successfully
- Column names assigned
- First five rows displayed
- Dataset information displayed
